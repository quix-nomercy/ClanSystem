# Changelog

## 1.0.0

- Clan create, delete, invite, info, accept, decline, leave, kick and list.
- Commands registered for the server console, Remote Admin and the player console, with configurable names and aliases.
- Server-Specific Settings menu with clan name field, player picker, status box and one button per action.
- Clan tag in front of the player name in the player list, with configurable format, color and upper case.
- Invites with expiry, expiry cleanup on round start and accept or decline by the target.
- Clan storage in `Configs/ClanSystem/clans.json`, with member nicknames kept for offline output.
- Every message and every menu label editable in the config.
- Optional permission flag and optional leader-only modes for delete, invite and kick.
